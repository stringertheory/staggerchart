Stagger chart

Each row is a forecast. Read across to see what was predicted that month, and down a column to see how the prediction for one month changed until the actual arrived.

What perfect forecasting would look like

The same months and the same actuals, with every forecast replaced by what actually happened. Each column holds one number all the way down, because the prediction never needed revising. For months with no actual yet, this assumes the trend in the actuals continues, with each month as far above or below it as the same month a year earlier.

Layout follows Andy Grove’s stagger chart in High Output Management.
